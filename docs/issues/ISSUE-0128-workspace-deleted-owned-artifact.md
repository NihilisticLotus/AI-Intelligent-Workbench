## 现象

用户在副本里删除项目原有的 .aic/TASK.md 后，更新任务账本会在原位置写出工作台说明。

## 复现步骤

在新建的临时 git 项目提交项目自有说明，创建工作副本；在副本删除该文件，更新约束，再发送普通消息。

## 影响

工作台改变了项目自有路径在工作副本中的状态，后续消息也没有按同名冲突规则内联正确约束。

## 根因

路径不存在就按空闲处理，没有检查基准与暂存区中的登记。

## 处理方式

发布前用受校验的工作副本核对 Git 基准与暂存区；与项目自有路径重合时保持删除，并内联账本说明。

## 验证

检查副本内文件仍不存在，原项目说明字节不变，实际接收的本轮消息含新约束。
