AI Console 界面原型

静态原型，用来评审布局、组件和配色。数据都是示例，大多数按钮没有接功能。设计说明见 docs/ui-design.md。

  • 工作台：对话侧栏任务列表、进行中的对话、工具调用、待审批卡片、交接分隔条，右侧改动面板。
  • 工作台：看板主区切到看板视图，按状态分列的并行任务；点“背包界面”卡片在右侧看摘要。
  • 资产预览Agent 改了模型后，右侧预览自动刷新；可一键全屏，和任务前对比。需要联网加载 three.js。
  • 生成用 ComfyUI、Codex 图片生成、音效服务生成图片、音效、视频：首次一键安装、内置入门模板、排队和进度、批量结果挑选、采用进资产目录。
  • 自动化定时和事件触发的任务：每晚构建、每周更新日志、新 FBX 自动检查。表单化设置触发方式和运行规则，不用写 cron。
  • 监控运行概览、近 7 天用量图表、Agent 健康、告警规则、最近事件，以及快速判断的卡住检测和准确度。
  • 能力把各 Agent 的 MCP 和 Skill 收拢到一处：扫描本机、对比差异、一键整合，所有 Agent 共用一套工具。
  • Agent 管理四个 Agent 的状态、登录过期、未验证版本、账号与测试连接。

可以试试

  • Ctrl+B 折叠或展开侧栏，Ctrl+J 显示或收起右侧面板；拖动右侧面板左边缘调整宽度，聚焦后也可以用方向键。
  • 侧栏底部切换深色和浅色，选择会被记住。
  • 工作台里点工具调用展开详情；点输入框下方的 Agent、账号、模型打开切换器。
  • 资产预览页点“全屏查看”或“和任务前对比”，Esc 退出；点“模拟 Agent 写入”看自动刷新。
  • 快速判断：审批卡片的“风险评估”、新建任务的“推荐 Agent”、测试通过后的“完成度判断”，都可以点 [不同意]；设置里的“快速判断”一节可以换判断引擎。
  • 窗口窄于 1280 像素时右侧面板变成覆盖抽屉；窄于 768 像素时变成单栏和底部导航。
