# ISSUE-0026：Claude 用户设置可能覆盖 API 账号路由

| 项 | 值 |
|---|---|
| 状态 | investigating |
| 类型 | bug |
| 严重程度 | 高 |
| 发现于 | [第 1.3 步真实补验](../acceptance/step-1.3.md) |
| 开启 | 2026-11-08 |
| 关闭 | |

## 现象

Claude 自定义地址测试返回与此前订阅链路相同的 429 额度错误。不能据此断言本次测试 Key 额度耗尽，也不能证明请求到达了指定接口。

## 复现步骤

1. 用户级设置包含 ANTHROPIC 路由变量的环境中创建另一个 API 账号。
2. 通过环境变量向新账号注入地址与密钥，同时保留 settingSources: ['user']。
3. 建会话并发送消息，观察实际链路是否仍被用户设置影响。

## 影响

显式选择的账号可能被已有设置覆盖，无法可靠确认计费与路由。

## 根因

锁定的 claude-agent-acp 0.100.0 源码说明：Claude Code 的 settings.json 中 env 会在子进程环境之后生效。当前接口仅注入进程环境，同时加载用户设置。没有读取用户的任何设置或凭据文件，尚未通过实际网络证据确认本机覆盖内容。

## 处理方式

待用户决定 API 账号是否不加载用户级设置。该选项影响用户设置、技能和 MCP 的继承，与 phase-1 §6.4.2 的原约定冲突，暂不擅自更改。

## 验证

已核对锁定版本源码的覆盖顺序；修复和真实复测未验证。

## 时间线

- 2026-11-08 开启：Claude 第 1 次带图消息返回 429；没有自动重发，已向用户说明配置隔离的取舍并等待决定。
