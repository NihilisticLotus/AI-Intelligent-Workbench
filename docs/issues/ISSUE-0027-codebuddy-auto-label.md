# ISSUE-0027：CodeBuddy 自动强度在提示和面板中显示 enabled

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 低 |
| 发现于 | [第 1.3 步真实补验](../acceptance/step-1.3.md) |
| 开启 | 2026-11-08 |
| 关闭 | 2026-11-08 |

## 现象

CodeBuddy 从 low 切回自动后，选择器显示正确，但对话的切换提示仍显示内部值 enabled；右侧上下文和默认设置也直接使用内部值。

## 复现步骤

1. 在 CodeBuddy 任务的选择器中先选 low，再选自动。
2. 查看切换提示、右侧上下文和 Agent 默认设置。

## 影响

同一强度在不同位置显示不一致。

## 根因

只有选择器调用 effortLabel，其余展示直接输出协议值。

## 处理方式

统一通过 effortLabel 展示，不修改发给 Agent 的内部值。

## 验证

浏览器真实任务的切换提示、触发器和右侧面板均显示自动，证据 `assets/step-1.3-codebuddy-auto-label.png`。类型检查、278 项默认测试和构建通过。
