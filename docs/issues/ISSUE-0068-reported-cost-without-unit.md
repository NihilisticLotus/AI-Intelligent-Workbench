## 现象

CodeBuddy Auto 的真实 usage_update 含 cost.amount，但 currency 是空字符串。面板显示“费用 2.15”，没有说明单位未知，容易被当作人民币或其他金额。

## 复现步骤

1. 打开本次 CodeBuddy 任务 t_Va5KrGUWYcuK 的详细面板。
2. 展开会话 token 用量；每轮 token 未报告，但底部显示无单位的费用数值。
3. 只读核对本次 session.usage，确认 currency 确实为空；不读取凭据。

## 影响

无法判断上游数值是金额还是积分，也不能用它与实际账单比较。没有错误推算 token，但费用提示缺少必要信息。

## 根因

网页仅检查 cost 对象是否存在，没有检查费用单位是否非空。标准字段允许字符串，而该上游返回空值。

## 处理方式

按既定“未报告则未知”规则：单位为空或纯空白时不展示无单位数字，显示费用未知并说明 Agent 未报告费用单位。已有人工预留仍明确标预留；有单位的真实零和非货币单位保持原始报告，不猜币种、不转换积分、不改原始事件。

## 验证

- 新增四项组件渲染测试：空串、空白、USD 零费用、明确 credits 单位。
- 修复后四项通过；临时去掉单位判断，空单位两项失败，恢复后四项通过。
- 完整检查与真实已有任务刷新复验待追加；不增加真实消息。
