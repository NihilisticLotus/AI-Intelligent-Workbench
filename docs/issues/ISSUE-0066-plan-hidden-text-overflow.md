# ISSUE-0066：计划辅助文字溢出导致定位时整页滚动

## 现象

长对话有计划时，点击上下文圆环定位右侧面板，整个页面向上偏移，顶栏消失，底部出现空白。

## 复现步骤

1. 在演示任务连续发送消息，保留对话中的计划与右侧展开计划。
2. 点击圆环或用 Tab、Enter 打开上下文。
3. 观察顶栏位置与浏览器外层滚动条。

## 影响

破坏固定工作台布局，干扰圆环、计划和后续对话导航的定位；不影响数据。

## 根因

计划状态的绝对定位辅助文字没有局部定位祖先，超出内部滚动区域后撑大根文档；根节点末尾播报区域另有 1px 边界溢出。

## 处理方式

计划列表建立相对定位容器；sr-only 使用标准负边距、无内边距和边框。保留辅助文字和内部滚动，不隐藏可访问内容。

## 验证

浏览器断言主区 top=0 且根文档高度=视口高度：临时移除两处修复并构建后，1510px / 720px、top=-256，失败；恢复源码并重建后，720px / 720px、top=0，通过。深浅主题均实际操作，三项检查见阶段记录。
