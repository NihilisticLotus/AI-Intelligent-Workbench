# ISSUE-0135：仅发送附件换 Agent 时接收方误收切回等待指令

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 中 |
| 发现于 | [1.6 完成后的代码审查](../acceptance/step-1.6.md) |
| 开启 | 2026-11-18 |
| 关闭 | 2026-11-18 |

## 现象

用户换 Agent 后只发送附件，附件送达，首轮请求却要求等下一条消息。

## 复现步骤

在临时任务上传普通说明文件，经 WebSocket 发送空正文、附件和目标 Agent，捕获接收方输入。

## 影响

接收方可能跳过用户已经发送的素材。

## 根因

输入构建只检查正文和内联的脱敏附件，未计入原样转交的附件。

## 处理方式

统一按正文、内联材料和实际附件判断本轮是否有用户请求。空的工作台切回和重新交接继续使用各自的控制指令。

## 验证

旧实现返回等待下一条消息。修复后同一附件编号与继续本轮任务的指令一同到达。

## 时间线

- 2026-11-18 代码审查发现，离线回归先失败、修复后通过。
