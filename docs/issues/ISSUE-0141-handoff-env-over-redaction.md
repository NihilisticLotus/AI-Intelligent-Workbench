# ISSUE-0141：环境文件里的普通配置值被全局打码

| 关闭 | 2026-11-19 |

## 现象

environmentValues 把环境文件的每一行和每个赋值值都加入全局打码集合，另有规则把任意 `大写名=值` 行整行打码。localhost、production、8080、true 这类值在转写、命令和用户消息里到处被换成 ***。

## 复现步骤

1. 让 Agent 读一份含 NODE_ENV=production、PORT=8080 的 .env。
2. 交接内容里“用 production 构建”“localhost:8080”等无关文本被打码。

## 影响

交接内容失真，新 Agent 读不懂命令和说明。

## 根因

打码集合没有区分密钥类值与普通配置值。

## 处理方式

只收录值得打码的值：去掉长度不足 6、纯数字、常见开关与环境名、本机地址；赋值行只收值不收整行，注释不收；名称像密钥（KEY、TOKEN、PASSWORD 等）的变量即使值很短也收。整行打码规则只针对名称像密钥的变量。环境文件本身的内容仍整体打码。

## 验证

`handoff-review.test.ts` 环境值用例；原有环境附件与历史查询的打码用例继续通过。
