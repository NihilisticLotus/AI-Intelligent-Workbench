# ISSUE-0145：取消交接确认后留下待确认记录、检查点和说明文件

|---|---|

| 关闭 | 2026-11-19 |

## 现象

开启“交接前让我确认”时，用户在确认框里返回草稿，交接记录停在 prepared，检查点引用和 .aic/handoffs 文件一直保留；Gateway 重启也不清理。

## 复现步骤

1. 开启确认，换 Agent 发送，在确认框里返回草稿。
2. 交接记录、refs/aic/checkpoints 下的引用和 .aic/handoffs/<n>.md 仍在。

## 影响

工作副本里堆积无用的检查点与说明，查看交接记录时出现永远“已生成交接内容”的条目。

## 根因

没有取消接口，网页取消时什么都不做。

## 处理方式

新增 `DELETE /tasks/:id/handoff/:handoffId`：只取消尚未开始发送的交接，记录标为 cancelled（协议只增），删除检查点引用和工作台写入且未被改动的说明文件。网页取消确认时调用；启动时清理上次停在确认框的交接。分隔条显示“已取消交接”。

## 验证

`handoff-review.test.ts`：取消后状态 cancelled、检查点与说明文件被删除、重复取消返回 409。
