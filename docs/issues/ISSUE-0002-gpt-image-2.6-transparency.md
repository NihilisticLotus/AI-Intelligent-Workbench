# ISSUE-0002：OpenAI Images 2.6 是否原生支持透明背景未确认

| 项 | 值 |
|---|---|
| 状态 | deferred（目标：媒体生成阶段） |
| 类型 | 外部依赖 |
| 严重程度 | 低 |
| 发现于 | 媒体生成调研的独立核查（research/media-gen.md 附录） |
| 开启 | 2026-11-06 |
| 关闭 | |

## 现象

调研报告原本写“gpt-image-2.6 原生支持透明 PNG/WebP”。两位核查员都没有找到官方来源：官方文档里的 `background: "transparent"` 只写在 gpt-image-2.5 的说明里。

## 影响

图标、UI 元素这类需要透明背景的游戏资产，云端默认方案不能想当然地选用 2.6。

## 处理方式

接入 `openai-image` 生成器时用 API 实测。在此之前，需要透明图时用 2.5，或者本机用 BiRefNet 抠图。

## 时间线

- 2026-11-06 开启：独立核查时发现。
