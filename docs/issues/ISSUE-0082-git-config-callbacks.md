## 现象与影响

worktree 检出以及 add / status 等操作可能触发用户 git 配置中的钩子、clean / smudge / process。外部程序能自行写原目录或访问网络，超出 G1 允许的必要元数据操作。

## 复现步骤

1. 在测试新建临时仓库配置 post-checkout 钩子和写标记文件的过滤器。
2. 创建工作副本、查看改动并合并。
3. 检查标记是否产生，以及用户 git 配置原文是否变化。

## 根因与处理方式

继承配置需要保留提交身份，却不能把任意程序也作为工作区管理器的附带执行能力。命令级关闭钩子、签名与 fsmonitor；读取过滤器键名后仅在本次命令覆盖为空，不写用户配置。自定义合并驱动无法安全代执行时停止合并，不执行驱动。影子快照改为原始字节对象，见 ISSUE-0083。

## 验证

钩子临时仓库用例已通过；过滤器专项与全量结果待追加。
