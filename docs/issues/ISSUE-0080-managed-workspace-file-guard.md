## 现象

把独立 Agent 的文件根切到副本后，读取项目规则返回 forbidden，模型请求尚未开始。

## 复现步骤

1. 在临时非 git 项目创建独立任务。
2. 副本位于数据目录的 worktrees/项目/任务。
3. 启动回合，既有数据目录保护拒绝读取副本内 AGENTS.md。

## 影响与根因

既有保护假定工作根不在数据目录中；新副本布局需要只开放登记的任务根，不能取消私有数据保护。

## 处理方式

Gateway 验证工作区登记、真实路径及状态后，传入受管理副本标记。TypeScript 和 Windows 宿主均验证数据目录下 worktrees/项目 ID/任务 ID 的固定结构。文件仍必须在当前副本内；相对路径敏感项、链接、硬链接、重解析点及句柄校验保持生效。其他私有目录不开放。

## 验证

新增真实 Windows 文件宿主用例：副本读写成功；越界、凭据路径、目录联接、硬链接、数据目录根拒绝。默认未经登记的路径不享有例外。全量结果待追加。
