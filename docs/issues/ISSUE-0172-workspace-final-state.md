# ISSUE-0172：重启后工作副本的结束状态可能与任务不符

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 高 |
| 发现于 | `6a163f5`，[第二轮审查](../acceptance/workbench-review-2026-11-21.md#第二轮审查) |
| 开启 / 关闭 | 2026-11-21 |

## 现象与影响

丢弃清理或最终状态写入之间中断，重启后看板仍可把任务列为待验收。

## 复现方法

在临时任务中让状态写入失败，再模拟旧版已清理副本但任务仍为待验收。

## 根因与处理

工作副本操作与任务状态以前分两次提交。现在同一事务保存两者，启动时按终态记录核对旧任务，副本已删除也能恢复。

## 验证

写入失败时副本和原任务都保留。清理后恢复的任务显示已丢弃，完成时间取自原操作。
