# ISSUE-0127：已发送环境附件的值未持续用于后续交接脱敏

| 项 | 值 |
|---|---|
| 状态 | investigating |
| 类型 | bug |
| 严重程度 | 高 |
| 发现于 | [1.6 实现审查](../acceptance/step-1.6.md) |
| 开启 | 2026-11-18 |
| 关闭 | |

## 现象

较早环境文本附件里的普通场景名和天气名，被后续约束引用时，可在交接正文、历史查询和副本任务说明中看到。

## 复现步骤

在暂建任务里发送带普通场景和天气配置的环境附件，将这两个值写入后续约束，切换到演示接收端。检查交接输入、当前任务的历史投影和工作副本中的说明。

## 影响

后续接收方可能看到本该隐藏的环境配置。

## 根因

附件里的环境值只参与随本条消息发送时的处理；任务说明和历史另走不同来源。带中文后缀的环境文件和带行尾注释的赋值也没有完整识别。

## 处理方式

从本任务已经发送的环境文本附件恢复脱敏依据；使用附件服务核对内容，预览、正文、历史和副本任务说明共用这些值。识别中文文件后缀和带引号或注释的普通配置。

## 验证

用虚构场景名、天气名验证后续正常消息仍能保留其余文字，而这两项不出现在接收材料、历史查询及任务说明内。

## 时间线

- 2026-11-18 审查时发现并建立定向回归，原实现断言失败。
