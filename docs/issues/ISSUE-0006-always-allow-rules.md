# ISSUE-0006：“总是允许”审批规则尚未实现

| 项 | 值 |
|---|---|
| 状态 | deferred（目标：第 1.3 步） |
| 类型 | 待办 |
| 严重程度 | 中 |
| 发现于 | 第 1.1 步审查（界面一致性） |
| 开启 | 2026-11-06 |
| 关闭 | |

## 现象

原型里审批卡片有“总是允许此类命令”的按钮，点击时会预览将要生成的规则。第 1.1 步还没有规则引擎（design.md 9.2），如果保留这个按钮，它的效果只会和“允许一次”一样，会误导用户。

## 处理方式

第 1.1 步先隐藏这个按钮，演示 Agent 也不提供这个选项。第 1.3 步实现项目规则（匹配、优先级、“始终禁止”清单）时一起恢复，并在点击时预览规则。

## 时间线

- 2026-11-06 开启：审查时发现，按钮已先隐藏。
