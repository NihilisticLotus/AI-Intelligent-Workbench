# ISSUE-0064：项目较多时侧栏新建任务按钮被挤扁

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 低 |
| 发现于 | [step-1.4 阶段 2](../acceptance/step-1.4.md) |
| 开启 | 2026-11-12 |
| 关闭 | 2026-11-12 |

## 现象

开发工作台侧栏展开多个项目，内容超过视口高度时，“新建任务”按钮被压缩，描边与文字过于拥挤。

## 复现步骤

1. 打开开发工作台，保持侧栏展开，并展开多个有任务的项目。
2. 让侧栏内容超过屏幕高度，观察顶部“新建任务”。
3. 修复前按钮实际高度约 20.8px，没有保持控件的 32px 高度。

## 影响

减小点击区域，破坏轻量化描边按钮的呈现；不影响任务数据。

## 根因

按钮位于纵向 flex 侧栏，默认允许收缩；只有 height，没有禁止 flex 压缩。

## 处理方式

仅给 sb-new 设置 flex: none，保持既定控件高度，长侧栏仍正常滚动。

## 验证

在真实浏览器页面新增高度断言（实际边界高度不少于 32px）：临时移除修复并构建刷新后，高度 20.791667938232425、断言 false；恢复修复并构建刷新后，高度 32、断言 true。深浅主题截图见阶段验收记录。没有新增镜像 CSS 的单元测试。
