## 现象

所有 git 调用都跳过 LFS 下载并禁用过滤器，包括在用户项目里执行的合并和撤销。任务改了 LFS 管理的资产（贴图、模型）时，合并会把几行指针文本写进用户项目，引擎打不开。

## 处理方式

不在工作台里下载 LFS 对象（会联网、可能很大），改为在写用户项目之前检查：合并的改动或撤销涉及的文件中有 `filter=lfs` 的，返回新的结果 `manual_required`（reason `lfs`）并列出文件，原项目不改动；“还原文件”对 LFS 文件同样拒绝。界面提示用自己的 git 工具处理。protocol 只增这个结果分支。

## 验证

- workspace-operations.test.ts 新增用例：带 `*.psd filter=lfs` 的临时仓库，任务改了 art.psd 时合并返回 manual_required，项目 HEAD 不变、文件未出现，还原文件被拒绝。临时去掉检查时失败。
