## 现象与复现

构造合法 5 MiB 二进制的 base64，交给 IndependentModelAttachment.parse；旧校验实际抛出 RangeError Maximum call stack size exceeded，尚未到模型请求或原有单图大小检查。新增解码总量测试最初也因此得到 request 而非预期 limit。没有真实模型调用。

## 影响与根因

承诺支持 5 MiB 图片，但旧整组重复正则在当前 Node / V8 对大字符串耗尽调用栈。输入长度没有越过既定限额，不能当作非法附件忽略。

## 处理方式

保留有界长度，改为长度整除四和简单字母表 / 末尾最多两个等号检查，保持旧语法；不扩大栈、不缩小图片限额。私有宿主回传复用同一检查。

## 验证

新增协议回归：合法 5 MiB 编码通过，空内容和末尾填充合法形式通过，不完整组 / 中间填充 / 空白 / URL 字母表拒绝。实际完整 PNG 恰为 5 MiB，经上传与 Windows 宿主读取后字节一致；不代表真实模型视觉能力。全量检查和修复提交随后追加。
