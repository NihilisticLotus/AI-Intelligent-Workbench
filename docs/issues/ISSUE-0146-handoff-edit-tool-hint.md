# ISSUE-0146：交接说明硬编码 Codex 的 apply_patch 工具名

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 低 |

| 关闭 | 2026-11-19 |

## 现象

ISSUE-0133 处理时，交接首条消息只在目标为 Codex 时追加“使用 Codex 原生 apply_patch”的说明，其他接收方没有编辑提示，工具名也写死在 Gateway 里。

## 复现步骤

1. 交给 Claude 等非 Codex 接收方，首条消息没有编辑工具说明。

## 影响

各家工具名不同，写死一家既不通用也会随版本失效；其他接收方仍可能沿用历史里的工具名。

## 根因

提示放在了 Gateway 的通用交接代码里并点名具体工具。

## 处理方式

改为对所有非只读接收方给出通用说明：“使用你自己的文件编辑工具……历史里的工具名属于上一会话”，保留“禁止命令也适用于读取文件”。

## 验证

`handoff-execution.test.ts` 与 `handoff-review.test.ts`：Codex 与 Claude 都收到通用说明，正文不含 apply_patch。真实模型行为未验证。

- 2026-11-19 开启：1.6 第二次代码审查发现。
- 2026-11-19 修复：见 1.6 验收记录“第二次代码审查”一节的提交。
