## 现象

独立 Agent 的 A 徽标在浅色主题呈白字浅灰底，不易辨认。

## 复现步骤

1. 在开发工作台打开一个独立 Agent 任务。
2. 点击侧栏主题按钮切为日间模式。
3. 观察回复与输入框的 A 徽标。

## 影响

削弱通过字母辨别 Agent 的能力；不影响任务执行与数据。

## 根因

通用的 `:root[data-theme="light"] .ag` 白字规则优先级高于 `.ag.independent`，覆盖了独立徽标需要的中性前景色。

## 处理方式

补充同主题下独立徽标的前景色规则，继续使用现有 fg-1 令牌，不改变身份或背景色。

## 验证

浏览器同一独立任务、浅色主题，以实际计算样式验证文字与背景对比度不少于 4.5：不包含修复的构建为 1.2133，断言 false；刷新包含修复的构建后为 13.8914，断言 true。截图见阶段 3 独立任务浅色证据。
