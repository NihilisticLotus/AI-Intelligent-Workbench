# ISSUE-0124：接收首轮审批到期仍会发布成功交接收据

## 现象

原生 Codex 的首轮工具审批到期，任务暂停，但原实现把交接写成 sent，并切为目标 Agent。

## 复现步骤

1. 临时项目中模拟接收 Agent 申请一次审批，等它到期后让适配器报告正常结束。
2. 另用同一夹具返回 refusal。核对任务当前 Agent、收据和来源下一轮。

## 影响

一次未完成的交接可能释放原会话名额，分隔条误报成功。

## 根因

结束条件排除了取消和错误，但没有核对该轮是否发生审批到期或明确拒绝。

## 处理方式

首轮和更正轮均需正常结束、没有取消或审批到期，才记录成功。失败沿用已有来源恢复流程，费用和原有记录保留。

## 验证

两个离线用例修复前均得到 sent，预期 failed。另核对后续消息回到原 Agent。

## 时间线

- 2026-11-18 开启。Codex 真实补验按停止条件结束，后续修复仅使用离线夹具。
- 2026-11-18 关闭。审批到期和首轮拒绝的两个回归均从 sent 失败变为通过，来源可继续；浏览器显示交接未完成。见 [本轮验收](../acceptance/step-1.6.md)。
