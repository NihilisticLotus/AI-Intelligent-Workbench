# ISSUE-0136：ACP 首轮请求把历史资料放在本轮用户指令之后

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 中 |
| 发现于 | [1.6 完成后的代码审查](../acceptance/step-1.6.md) |
| 开启 | 2026-11-18 |
| 关闭 | 2026-11-18 |

## 现象

Gateway 内联交接时历史在前，ACP 传递资源时顺序相反。

## 复现步骤

用本地协议夹具发送任务说明、历史资料和当前指令，分别捕获支持和不支持资源嵌入时的内容数组。

## 影响

不同适配路径可能使接收方以不同顺序理解历史与当前任务。

## 根因

ACP 组包先追加用户文字，再追加工作台资源，与计划第 12.9 节的顺序不一致。

## 处理方式

先组装工作台资源，再追加本轮用户指令和用户附件。普通聊天和附件的相对顺序沿用原流程。

## 验证

两个协议夹具用例在修复前均读到用户文字在首位，修复后均通过。此项不能证明此前真实 Luna 止于复述的原因。

## 时间线

- 2026-11-18 代码审查发现，离线回归先失败、修复后通过。
