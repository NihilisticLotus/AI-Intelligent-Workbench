# ISSUE-0157：手机时钟偏差造成配对倒计时和重试时间错误

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 中 |
| 发现于 | `16e0c4b`，[1.7 审查记录](../acceptance/step-1.7.md) |
| 开启 / 关闭 | 2026-11-21 |

## 现象与影响

手机时间比电脑慢时，服务端已经解除限流，页面仍可能禁用按钮数小时。手机时间偏快时，待确认倒计时可能从一开始就显示零。

## 复现步骤

保持系统时间不动，用不同的手机页面时间检查同一条等待确认和限流响应。

## 根因与处理方式

配对等待与限流响应附上可选的服务端当前时间。网页把剩余时长换算到设备自己的时钟。查询发现请求已不存在时立即结束等待。

## 验证

用例覆盖快钟、慢钟、已经到期和旧协议响应。配对成功或超时仍由 Gateway 裁定。
