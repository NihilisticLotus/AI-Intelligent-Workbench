# ISSUE-0154：访问审计清理误删其他模块的历史记录

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 高 |
| 发现于 | `16e0c4b`，[1.7 审查记录](../acceptance/step-1.7.md) |
| 开启 / 关闭 | 2026-11-21 |

## 现象与影响

Gateway 启动与每小时清理时，共用审计表里超过 90 天的数据库迁移、账号或模型目录审计也会被删除。

## 复现步骤

在临时数据库写入同样超过 90 天的一条访问记录和一条迁移记录，执行访问审计清理。

## 根因与处理方式

原查询只检查时间。清理现与访问日志列表一样，限定操作名前缀为 `access.`。

## 验证

迁移记录在旧实现中消失。修改后，过期访问记录被删除，迁移记录仍可查。

## 时间线

- 2026-11-21 代码审查发现，补充回归并修复。
