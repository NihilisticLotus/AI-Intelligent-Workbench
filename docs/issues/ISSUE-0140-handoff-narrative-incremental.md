# ISSUE-0140：第二次交接的摘要只看新事件，丢掉上次的尝试与决策

| 项 | 值 |
|---|---|
| 状态 | fixed |

| 发现于 | [1.6 完成后的第二次代码审查](../acceptance/step-1.6.md)（审查范围 5dc0c9c..72adaf5） |

| 关闭 | 2026-11-19 |

## 现象

配置摘要模型后，第二次及以后的交接只把上次交接之后的转写交给摘要模型，结果直接作为本次叙述，上次的尝试、决策和未决问题全部丢失。

## 复现步骤

1. 配置摘要模型，交接一次，再交接第二次。
2. 第二次的 attempts / decisions 只有新内容。

## 影响

多次交接后新 Agent 看不到较早的失败尝试和已定决策，可能重复走弯路。design 7.5.2 要求增量合并。

## 根因

preview.ts 的增量分支没有读取上次交接文档的叙述字段。

## 处理方式

把上次已发送交接的叙述作为基础传给摘要模型（要求在其上更新），并在本地合并：尝试与决策去重累积，未决问题与当前进展取本次结果、缺失时沿用上次。合并结果照常经过一致性校验。

## 验证

`handoff-review.test.ts` 的 mergeNarrative 单元测试。真实摘要模型的合并效果未验证。
