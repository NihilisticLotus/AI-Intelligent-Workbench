# ISSUE-0143：交接守卫按会话查询事件但没有索引

| 关闭 | 2026-11-19 |

## 现象

交接后的行为守卫在每个工具事件上按 session_id 查询 events，复述核对也按 session_id 查询；events 只有 (task_id, seq) 索引，会扫描整张表。

## 复现步骤

1. 事件库很大时交接，接收方每次工具调用都触发一次全表扫描。

## 影响

事件多时界面与 Gateway 卡顿。

## 根因

缺少 events(session_id, seq) 索引。

## 处理方式

新增迁移建立 idx_events_session(session_id, seq)。

## 验证

`handoff-review.test.ts` 检查索引存在；全部迁移相关测试通过。
