# ISSUE-0158：网卡转为公用网络后第二监听仍在运行

| 项 | 值 |

| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 高 |

| 开启 / 关闭 | 2026-11-21 |

## 现象与影响

启动和开启时检查了网络类别，运行中的网卡更换网络后，已有局域网连接和第二监听仍可能保持开启。

## 复现步骤

在全注入的网络替身中启用专用网卡并建立 WebSocket，再把替身类别切为公用。

## 根因与处理方式

监听生效期间每分钟复查所选网卡，设置页读取状态时也会核对。网卡消失、类别未知或不再专用时暂停监听、断开连接，保留用户的开启意图。旧查询结果按监听实例区分。电脑设置可刷新网卡状态，恢复后点“更新规则”重新连接。

## 验证

回环测试覆盖关闭已有 WebSocket、保留本机服务、无提权和手动恢复。运行中暂停写入访问审计，电脑页面收到状态更新。
