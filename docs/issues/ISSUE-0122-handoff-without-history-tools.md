## 现象

智谱独立接收端正确复述了目标和 Level.txt，随后说必要时可用 aic_history 回查。该任务把工具次数设为零。离线小窗口的 H4 分隔条也显示“使用确定性记录与本任务历史查询”。

## 复现步骤

1. 在新建的临时 git 项目把关卡任务从演示 Agent 交给禁用工具的独立 Agent，读取同一任务的交接收据。
2. 本机回环以 10000 token 窗口接收长记录，无摘要时 H4，有回环摘要时 H3。只检查实际执行请求中的工具数、正文是否指向历史工具，并与分隔条比较。

## 影响

模型和用户都可能把本次无法执行的历史查询当作可用。短会话可从完整转写复核，较长会话的部分资料只在工作台历史中。

## 根因

交接渲染和网页 H4 说明固定提到历史工具。独立运行时按已有配置限制工具次数，零次时实际请求中不提供工具。ACP 的会话级 MCP 注入与独立运行时的工具清单是两条不同的路径。

## 处理方式

有真实依据的文件与命令仍可内联。手动关闭全部工具时，长会话是继续自动交接并说明可查范围，还是保留来源等用户选可查询的配置，待用户决定。两种处理都保留原工具次数和额度。

## 验证

智谱真实接收一次，历史调用零次；复述提到该工具。两次离线请求的工具清单都为空，正文都指向 aic_history。H3 探针 7/8，H4 无探针。截图见阶段 7 验收。

## 时间线

- 2026-11-18 开启。已停止真实验证，本现象未追加任何模型请求。
