# ISSUE-0166：网页把尚有下一页的任务、账号或长对话标为完整

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 高 |
| 发现于 | `09f5793`，[全工作台审查](../acceptance/workbench-review-2026-11-21.md) |
| 开启 / 关闭 | 2026-11-21 |

## 现象与影响

账号及任务列表超过固定页数时被截短，对话在第两百页之后静默停止。用户可能找不到任务、账号和一段确实存在的对话。

## 复现方法

提供连续 53 页列表和 201 页对话事件，再分别返回重复游标或停滞的事件序号。

## 根因与处理

客户端用固定循环次数作为结束条件，达到上限直接返回成功。读取到服务端明确返回末页，异常游标使本次加载失败。设备会话切换后丢弃旧的历史响应。

## 验证

`apps/web/src/api/pagination.test.ts` 验证末页、重复游标和长对话。
