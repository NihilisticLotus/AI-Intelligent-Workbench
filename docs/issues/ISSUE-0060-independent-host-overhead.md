# ISSUE-0060：独立 Agent 的几处重复开销：每个流式片段查库、看图和改文件反复启动受控宿主

## 现象

1. model-driver.ts 的 emit 对每个流式片段都核对绑定，catalog.bound() 每次同步查库并重新解析服务、模型和全部能力证据。
2. 附件下载每次都经受控宿主读取（两层 PowerShell 加一次 C# 编译），接口统一 no-store，网页缩略图每次挂载都重新请求。
3. 一次文件修改在审批前后各做一遍计划，每遍分别启动宿主读规则和读原文，加上写入至少 5 次宿主启动。

## 影响

长回复期间拖慢 Gateway 事件循环；带多图的消息每次打开要十几秒才出齐缩略图；连续修改文件时大部分时间花在进程启动上。不影响正确性。

## 处理方式

未改。方向：绑定核对改为按时间间隔；网页按任务和附件 id 缓存图片；规则与原文合并成一次宿主请求或复用已编译的守卫程序集。这些都涉及已有的安全设计，放到 1.4 性能整理时一起做并补测试。
