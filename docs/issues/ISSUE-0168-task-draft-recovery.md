# ISSUE-0168：草稿可能被临时断线、旧保存或旧标签页覆盖

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 高 |
| 发现于 | `09f5793`，[全工作台审查](../acceptance/workbench-review-2026-11-21.md) |
| 开启 / 关闭 | 2026-11-21 |

## 现象与影响

草稿读取失败后可能被当成空稿写回，清空和旧保存可能反序完成，重新打开同一任务还可能读到旧内容。未发出的消息、注释及附件引用可能丢失，已经发出的文字也可能重新出现。

## 复现方法

预存草稿后让第一次读取返回 503，等过自动保存时间再重试。另延迟前一次保存后发送，在另一个标签页续写后重新打开。

## 根因与处理

读取失败和空草稿被合并，成功响应长期缓存，并发写入缺少顺序。恢复注释时还会保留旧内存列表和可能重复使用的本页编号。读取失败提供重试，保留原稿和正在输入的内容。每个任务串行保存，离开再进入时重读，退出会话清缓存。恢复附件区分缺失和暂时不可读。新增注释使用独立标识。

## 验证

`apps/web/src/state/drafts.test.ts` 验证读失败重试、跨设备取新和清空顺序。浏览器注入一次读取故障并通过两个标签页续写。
