# ISSUE-0049：Gateway 兜底终端错误输出绕过脱敏

| 项 | 值 |
|---|---|
| 状态 | investigating |

| 发现于 | [1.3 零调用稳定核查](../acceptance/step-1.3.md)；基线 939e057 |
| 开启 | 2026-11-08 |
| 关闭 | |

## 现象

致命异常文件日志已脱敏，终端却直接输出原始 message；启动失败、任务、HTTP / WebSocket 与事件订阅者也有直接打印异常的出口。附带请求或附件的 Error 对象可被终端对象检查展开。仅以合成数据复现，未确认实际凭据或附件曾泄露。

## 复现步骤

1. 在隔离测试安装崩溃处理器，传入含合成 Bearer 字段的 Error 或字符串。
2. 触发 uncaughtException；收集注入的终端输出函数与临时文件日志。
3. 修正前两项回归均证实：文件隐藏合成凭据，终端保留原文。不使用真实凭据，也不调用 Agent。

## 影响

异常恰好带凭据时可能进入终端；异常附带的对象字段也可能包含不应记录的数据。违反既定日志约束，与 ISSUE-0015 原始 Gateway 退出原因是不同问题。

## 根因

文件记录与部分适配器路径使用现有 redact，以上终端兜底分支未使用；直接 console.error 异常对象还会展开其可枚举附带字段。

## 处理方式

共用异常日志格式函数：Error 保留脱敏堆栈，字符串脱敏，其他对象省略附带数据；不调用自定义字符串转换。任务带入已有本轮密钥列表；HTTP 去除原始路径。崩溃处理器的终端出口统一脱敏，原始 onFatal 参数与只收尾一次语义保留。没有新依赖、协议、认证或界面改动。

## 验证

修正前崩溃回归 4 通过 / 2 失败；修正后崩溃与新增日志回归共 14 项通过，覆盖 HTTP 500、WebSocket 失败 ack、任务 failed / 脱敏事件、订阅者继续处理、Error 附带数据及非 Error 对象。真实 Gateway 入口在合成无效数据目录上退出 1，终端隐藏路径内合成 token，禁用真实 Agent。类型检查与构建通过；全量测试结果和提交哈希随后追加。未读取真实凭据，未验证曾发生真实泄露。
