## 现象

本机可以在隔离的 Chrome 预览中完成局域网配对和演示审批。用户本轮无法使用手机或另一台电脑复核，局域网真机链路和实际 Windows 权限窗口暂无结果。

## 复核步骤

1. 用户在电脑页面开启局域网并确认 Windows 权限窗口，手机接入同一 WiFi。
2. 手机输入配对码，电脑确认后用演示 Agent 完成一次审批，随后验证需要电脑确认的操作。
3. 分别在竖屏和横屏操作，观察软键盘、相册和相机。验收结束后吊销手机并关闭局域网，核对规则已移除。完整步骤见 [1.7 验收记录](../acceptance/step-1.7.md#2026-11-19-阶段-7真机复核步骤)。

## 影响

第 1.7 步的真机验收条件仍待满足。浏览器模拟能核对页面布局与流程，系统键盘、媒体选择、跨设备连接、UAC 与规则安装和删除需要在实机上观察。

## 根因

本轮没有可用的真机验证窗口。未观察到实际设备故障。

## 处理方式

先交付本机测试和浏览器验收，保留现场记录项。等有可用手机时按文档复核，实机通过后再关闭问题单和第 1.7 步。

## 验证

待登记手机型号与系统、浏览器与版本、网络类别、UAC 结果、入站规则添加和删除结果、Windows 是否另弹“允许访问网络”，以及竖屏、横屏、软键盘、相册、相机和吊销结果。可用时补测另一种手机系统。
