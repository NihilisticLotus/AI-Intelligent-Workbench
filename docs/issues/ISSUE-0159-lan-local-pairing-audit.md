# ISSUE-0159：本机配对请求和失败结果缺少访问审计

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 中 |
| 发现于 | `16e0c4b`，[1.7 审查记录](../acceptance/step-1.7.md) |
| 开启 / 关闭 | 2026-11-21 |

## 现象与影响

电脑请求新码或配对失败时，在“设备与访问”的审计日志中看不到对应记录。

## 复现步骤

在临时本机实例请求一次配对码，提交错误码，然后读取访问审计。

## 根因与处理方式

给本机请求新码以及配对失败、限流补记操作、来源与结果。成功配对继续记新设备编号。

## 验证

离线测试核对发码和失败记录以及设备输入不进入日志。

## 时间线

- 2026-11-21 代码审查发现，补充回归并修复。
