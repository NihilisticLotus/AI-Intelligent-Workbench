# ISSUE-0156：电脑新标签页漏掉已有的待确认请求

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 中 |
| 发现于 | `16e0c4b`，[1.7 审查记录](../acceptance/step-1.7.md) |
| 开启 / 关闭 | 2026-11-21 |

## 现象与影响

手机请求已经发出后再打开电脑标签页，新页面只从当前事件游标往后订阅。此时关闭原标签页，会留下无人能在界面上处理的请求。

## 复现步骤

保持一个本机页面在线，先发起配对和敏感操作，再打开另一本机页面，从最新游标订阅。

## 根因与处理方式

本机浏览器订阅成功时，Gateway 在同步完成帧附上仍有效的待确认队列，按原始事件顺序排列。网页先处理补发事件，再用该队列校准弹窗。

## 验证

离线测试检查两类确认、先后顺序、空队列和局域网设备的可见范围。

## 时间线

- 2026-11-21 代码审查发现，补充回归并修复。
