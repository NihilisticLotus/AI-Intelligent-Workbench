# ISSUE-0134：工具记录归并不完整影响转写脱敏与已读清单

| 类型 | bug |
| 严重程度 | 高 |

| 关闭 | 2026-11-18 |

## 现象

转写可能漏掉较早一次工具的名称、结果及环境来源标记；已读清单也可能遗漏稍后才获取路径的成功读取。

## 复现步骤

在临时任务用合成工具事件核对两次读取及其中一种分步上报的路径，查看交接预览。

## 影响

影响交接事实的完整性，环境文件输出可能未经预期的整段打码。

## 根因

转写只对每个编号的最后一次调用生成说明。统计读取只看开始事件中的类型和路径。

## 处理方式

转写独立保存每次调用，后续事件绑定最近一次调用。读取计数合并本次开始与更新，仅在成功结束时入账。

## 验证

修复前预览漏掉早期工具说明、显示合成配置正文、缺少稍后上报的文件。修复后这三项与后续工具说明均通过。

## 时间线

- 2026-11-18 代码审查发现，离线回归先失败、修复后通过。
