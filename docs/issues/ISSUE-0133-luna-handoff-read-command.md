# ISSUE-0133：Luna 接手仅新增文件的任务时尝试用命令读取旧文件

| 项 | 值 |
|---|---|
| 状态 | open |
| 类型 | 验收未通过 |
| 严重程度 | 中 |
| 发现于 | [1.6 真实交接接续](../acceptance/step-1.6.md) |

| 关闭 | |

## 现象

Luna 正确复述既有成果和下一步，随后发起 PowerShell 读取 Level.txt 和 Rules.txt 的调用。验收守卫取消该调用，未发出编辑审批。

## 复现步骤

1. 使用验收临时库中已完成的 Claude 首轮，从任务的正常发送入口向 Luna 发一条接手消息。
2. 对照助手回复、工具开始和结束事件、交接状态及文件清单。

## 影响

本次接手回合失败，任务回到 Claude，真实 Luna 写入和完整的切回回忆未验证。

## 根因

原请求说“不用运行命令”，验收守卫则禁止所有命令；交接正文要求先读正在改的文件，首轮要求说明准备先读哪些文件。这次只需新增文件，识别词已经在转写中。原生回复明确表示打算用旧文件核对识别词，紧跟着发起读取命令。不能确定模型会如何解读其他等价措辞。

## 处理方式

接收提示明确仅新增文件时可用已知内容直接完成，用户禁止命令同样约束读取。验收消息明确禁止用命令读取文件；保留守卫与原权限。

## 验证

修复前捕获真实发送入口构建的输入，断言缺少命令限制说明而失败；修复后 3 个离线条件用例通过。更新后的真实模型行为未验证。

## 时间线
