## 现象

新增规则按 Alt+↑ 后顺序变化，但焦点落回页面，无法连续调序。

## 复现步骤

1. 项目设置中新增第二条规则。
2. 聚焦第二行，按 Alt+↑，查看焦点；不重新点击时继续 Alt+↓ 无法作用于该行。

## 影响

键盘操作需要重复定位，未保存的新规则尤其明显。

## 根因

新增规则使用数组下标作为 React key，调序后重新挂载。

## 处理方式

每行保留稳定的界面编号，保存请求剥离此编号；业务编号仍由服务端生成。

## 验证

浏览器修复前焦点回页面；修复后连续 Alt+↑、Alt+↓ 均移动同一行并保持焦点。鼠标拖动也验证通过，深浅主题均检查。
