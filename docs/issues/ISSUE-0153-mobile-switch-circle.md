# ISSUE-0153：触屏断点内开关被压成圆点

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 低 |
| 发现于 | [第 1.7 步代码审查](../acceptance/step-1.7.md) |
| 开启 | 2026-11-19 |
| 关闭 | 2026-11-19 |

## 现象

1279 像素以下，设置页的“局域网访问”“页面提醒音”和 Agent 卡片上的开关显示为 44×44 的圆形，看不出胶囊轨道，开与关难以区分。

## 复现步骤

1. 开发预览设为 375×812。
2. 打开“设置”，查看开关：实测 44×44，圆角为胶囊。

## 影响

手机上开关状态不易辨认，桌面不受影响。

## 根因

阶段 6 为保证触控区，给所有按钮加了 `min-block-size` 与 `min-inline-size` 44px。开关本身是胶囊形按钮，被同时撑高撑宽后成了圆。

## 处理方式

断点内开关用 9 像素透明边框和 `background-clip: padding-box`：可见轨道仍为 44×26 胶囊，触控区为 62×44。圆点位置按新轨道调整。

## 验证

375×812 深浅主题下实测开关 62×44，开、关两态均为胶囊。1440×900 下仍为 44×25。
