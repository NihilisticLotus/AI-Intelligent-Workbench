# ISSUE-0173：一个无法删除的过期附件会打断启动清理

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 高 |

| 开启 / 关闭 | 2026-11-21 |

## 现象与影响

Gateway 启动和定时清理都遍历过期附件。遇到单个无法删除的文件，后续附件无法处理，启动也可能失败。

## 复现方法

用临时目录替代一个合成附件的文件位置，同时保留另一个过期附件和一个已引用附件。

## 根因与处理

逐项捕获文件删除错误并保留对应数据库记录。清理继续处理其他项，汇总失败数量，下一轮重试。

## 验证

第一次只留受阻和已使用的附件。移走临时障碍后再次清理成功，已使用的附件仍可读取。

## 时间线

- 2026-11-21 第二轮审查中定位并修复。
