## 现象

独立 Agent 的每次读取都走审批流程，自动允许时一律发“已自动允许：只读操作”，读多个文件时对话被刷屏。

## 处理方式

没有命中项目规则的普通读取不再发提示；按项目规则放行的，以及自动档放行的修改和命令仍留一行记录。

## 验证

- permission-api.test.ts 新增用例：三次无规则读取全部自动允许，对话里没有“自动允许”提示；原“已按规则自动允许”用例继续通过。
