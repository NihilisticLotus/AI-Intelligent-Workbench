## 现象与影响

到期计时器尚未获得执行机会时，操作可能在截止时刻或之后仍被确认。

## 复现方法

用离线审批夹具分别在提交前和异步规则核对期间将测试时钟推进到截止时间。

## 根因与处理

接收审批和实际提交前均核对截止时间。预览与定时器使用同一套到期判断和收尾。

## 验证

两个时序均只登记一条过期事件。演示 Agent 收到取消，任务转为暂停。
