## 现象与影响

浏览器入口存在但引用的脚本或样式缺失时，双击启动跳过构建。用户可能看到白屏或缺少样式，需要开发人员介入。

## 复现方法

在临时目录写入入口，依次只放脚本、补齐样式，再让依赖锁的修改时间较新。

## 根因与处理

启动器只对比入口时间与部分源码时间。检查入口引用的本地构建资源确实是非空文件，把依赖锁与相关构建配置纳入新旧比较。

## 验证

`packages/gateway/test/startup-assets.test.ts` 直接调用启动器使用的判断函数，隔离验证缺少资源、产物完整和依赖更新。
