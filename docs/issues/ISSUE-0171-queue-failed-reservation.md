# ISSUE-0171：任务登记排队状态失败会永久占用执行名额

## 现象与影响

通知立即分配失败仍保留活动名额。等待入队时写任务状态失败，该任务仍在队列，轮到它之后无人归还名额。现有任务结束后，新任务仍可能一直等候。

## 复现方法

将并发上限设为一，注入抛错的状态写入或通知，再释放前一个任务并尝试立即分配下一个任务。

## 根因与处理

先修改内存名额或队列，再执行可能失败的回调，异常路径没有撤回占位。立即分配通知失败时撤回活动名额，排队登记失败时移除等待者与取消监听。

## 验证

`packages/gateway/test/task-queue.test.ts` 两个新增用例分别核对剩余名额与下一任务能否进入。
