# ISSUE-0107：写任务说明时解密了与内容无关的工作台旧密文

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | 验收未通过 |
| 严重程度 | 中 |
| 发现于 | [1.6 阶段 1 验收](../acceptance/step-1.6.md) |
| 开启 | 2026-11-18 |
| 关闭 | 2026-11-18 |

## 现象与复现步骤

使用原生配置迁移测试中的假适配器和内存密钥仓。创建新任务后，读密钥的监测记录了一次调用。

## 影响

即使内容与旧配置无关，也会解密工作台数据库中保留的密文。

## 根因

说明发布前枚举并解密所有记录，未先检查待发布文字。

## 处理方式

先用数据库中已有的末四位排除不可能命中的记录。剩余候选在 Gateway 内存中做精确替换，再截断文本；没有末四位提示的短值也参与匹配。

## 验证

原生配置回归和新增的合成密钥替换用例已进入全量复验。没有读取第三方软件的凭据文件。

## 时间线

- 2026-11-18 开启并定位于阶段 1 本地验收。修复后等待全量复验。
- 2026-11-18 原生配置用例及合成短 Key 用例已通过。未涉及任何第三方凭据文件。
