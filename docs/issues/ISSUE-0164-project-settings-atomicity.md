# ISSUE-0164：项目或分组可保存空名称且多项修改可能只生效一部分

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 中 |
| 发现于 | `09f5793`，[全工作台审查](../acceptance/workbench-review-2026-11-21.md) |
| 开启 / 关闭 | 2026-11-21 |

## 现象与影响

全空白名称能保存成空串，批量修改时后一个字段失败，前面的字段已经生效。侧栏可出现没有名称的条目，报错后显示的数据与用户预期不同。

## 复现方法

提交仅含空白的分组名称。另在临时库令项目设置的第二条写入失败，再读回项目名称。

## 根因与处理

校验先于去空白，多字段更新使用独立提交。在请求边界去空白后校验，项目和分组整次更新使用同一事务，移除分组时一起保存任务回归未分组的事件。

## 验证

`packages/gateway/test/tasks.test.ts` 在 REST 入口检查无效输入，并在服务层注入数据库写入失败后核对原始值。
