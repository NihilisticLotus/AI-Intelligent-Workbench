# ISSUE-0081：统计相同时单文件差异可能停留在旧内容

| 关闭 | |

## 现象

同一路径被改成同字节数、同增删行数的另一段内容时，列表摘要相等，网页复用了旧列表对象，单文件差异未重新读取。

## 复现步骤

1. 改动面板打开 modify.txt，文件由“旧内容”改为“新内容”。
2. 再把“新内容”改成“另内容”，文件大小与行数不变。
3. 刷新列表仍相等，单文件面板可能显示“新内容”。

## 根因与处理方式

列表摘要不能充当内容版本。协议追加可选 revision，Gateway 用已计算的基准与文件摘要生成内容修订标识；列表比较包含该标识，内容变化后重读补丁。改动事件仍只发送任务 ID 和合计。

## 验证

新增同统计不同内容的接口回归；全量与界面结果待追加。

## 时间线

- 2026-11-15 开启：阶段 3 自查发现，追加内容修订标识并补用例。

- 2026-11-15 修复：同统计内容用例、撤修失败、全量 940 通过 / 3 跳过；浏览器自动刷新到“另内容”且合计不变。状态 fixed，关闭日期 2026-11-15；提交随阶段 3 记录。
