## 现象

初稿忽略以短横线开头的命令参数，等号形式的目标路径可能漏检；通配使用多个贪婪星号组成的正则，失败匹配可能产生大量回溯。尚未发布。

## 复现步骤

1. 对带原项目路径的 npm install --prefix=参数判定，覆盖普通值与单双引号值。
2. 用多段星号和字母组成的规则匹配长字符串，结尾故意不匹配。

## 影响

原项目目标漏检可能被允许规则放行；复杂规则可能阻塞 Gateway。

## 根因

命令参数只检查位置参数；通配复用回溯正则而没有工作量上界。

## 处理方式

解析等号选项值和引号；复杂脚本仍不自动允许。通配改为动态规划，工作量由两侧输入长度限定，不解释正则字符。

## 验证

专项 25 项通过。临时撤掉等号参数解析，新增 3 项真实失败；恢复后随全量复验。没有实际执行该命令。
