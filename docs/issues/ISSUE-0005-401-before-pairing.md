| 状态 | open |

## 现象

首次打开、还没配对时，浏览器控制台里有 3 条 401 请求记录。

## 影响

功能正常，但控制台有噪音；排查问题时容易被误导。

## 处理方式

网页启动时先检查本地是否有凭据。没有凭据时直接进入配对流程，不去请求需要鉴权的接口。
