## 现象

全量离线测试中，虚拟时钟到 60 秒时应有一条提醒，实测零条。单独运行该用例也能复现。

## 复现步骤

运行 Gateway 的 step-1.3.test.ts 中“60 秒提醒、同 id 两分钟替换、10 分钟取消并暂停”。

## 影响

全量验收不能稳定区分会话启动期间的异步文件检查与 Agent 收到消息后的等待。

## 根因

提示请求返回并推进零毫秒时，工作副本路径核对还可能在进行。无回应计时在这个核对完成后、调用适配器之前才启动。

## 处理方式

测试中的模拟适配器在收到消息并注册取消监听时发出就绪信号。收到信号后再推进虚拟时间，取消后等本轮异步工作结束再读取最终状态。产品的计时逻辑沿用原实现。

## 验证

修复前单测在第一个提醒数量断言失败，修复后定向通过。原 60 秒提醒、同一编号两分钟更新、10 分钟取消、暂停及错误码断言均保留。

## 时间线

- 2026-11-18 全量发现，单独复现并完成定向修复。相关审批计时的既往问题见 [ISSUE-0121](ISSUE-0121-approval-watchdog-test-start.md)。
