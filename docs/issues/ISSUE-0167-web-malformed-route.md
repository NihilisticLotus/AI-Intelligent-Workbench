# ISSUE-0167：截断的任务网址会让工作台无法显示

## 现象与影响

从聊天工具复制的任务链接若缺失部分百分号编码，打开后页面停在空白。书签或外部链接损坏时，用户无法通过页面返回。

## 复现方法

打开片段为 `#/t/%E4` 的工作台网址，并对比有效的中文及百分号编码。

## 根因与处理

模块初始化时直接解码网址，URIError 阻止路由和应用启动。片段解码失败时回到首页，合法标识沿用已有解析。

## 验证

`apps/web/src/api/pagination.test.ts` 覆盖四类损坏片段与有效编码，另用浏览器实际进入。
