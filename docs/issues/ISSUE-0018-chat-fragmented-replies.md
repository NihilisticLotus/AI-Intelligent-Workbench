# ISSUE-0018：思考强度提示堆叠；Agent 回复被拆成多条

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 中 |
| 发现于 | 用户人工验证（2026-11-07） |
| 开启 | 2026-11-07 |
| 关闭 | 2026-11-07 |

## 现象

1. 来回切换思考强度，对话里每次都多一行“已切换为思考强度 xxx”。原型里修过，正式网页里没有。
2. Codex 在工具调用之间分段输出，每一段都显示成一条带头像、名称和“正在思考”的独立消息，前面几段一直转圈。常见的 Agent 软件里，一轮回复只是一条消息。
3. 思考内容里的 `**粗体**` 原样显示。

## 根因

- `buildTimeline` 每收到一次 `session.config` 就新增一行提示。
- Agent 每一段用新的 messageId，时间线为每段建一条消息；只有最后一段收到 `message.done`，前面的段落没有结束标记。

## 处理方式

- 连续的配置变化（中间没有新消息）合并成一行，显示最终结果。
- 同一轮（两条用户消息之间）的后续片段标为 `cont`，界面不再重复头像和名称；新片段、新工具调用或新的用户消息开始时，把之前未结束的片段标为结束，思考记下结束时间。
- 思考内容按 Markdown 渲染。

## 验证

- 新增 `apps/web/src/state/timeline-grouping.test.ts`，共 3 项。
- 浏览器实测：用演示 Agent 的分段任务打开对话，整轮只显示 1 个头像（3 段中 2 段为续段），没有残留的“正在思考”。

## 时间线

- 2026-11-07 开启并修复。
