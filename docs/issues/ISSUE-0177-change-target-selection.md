# ISSUE-0177：工具记录可能打开并允许还原另一个文件

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 高 |
| 发现于 | `6a163f5`，[第二轮审查](../acceptance/workbench-review-2026-11-21.md#第二轮审查) |
| 开启 / 关闭 | 2026-11-21 |

## 现象与影响

点击工具记录里的“在改动面板中查看”，可能选中无关文件并显示它的还原入口。

## 复现方法

在临时副本中同时修改根目录和子目录的同名文件，分别从缺失文件和子目录文件的工具记录点击查看。

## 根因与处理

按当前任务和副本根目录核对完整相对路径。找不到文件时保留提示，可以刷新或手选。重命名按当前改动名称展示。

## 验证

旧构建选中了根目录的同名文件。修复后匹配缺失时不显示还原按钮，手选及子目录定位均能读到对应差异。

## 时间线

- 2026-11-21 第二轮审查中定位并修复。
