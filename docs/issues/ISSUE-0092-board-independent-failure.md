## 现象

本机离线 HTTP 夹具返回 503 后，独立任务状态 failed，看板只显示“本轮未完成”，没有显示服务失败原因。

## 复现步骤

1. 在本步新建的临时项目，用本机 127.0.0.1 离线模型夹具返回 HTTP 503。
2. 看板失败列只见通用提示；任务独立状态接口保存了本轮 model_error 和 upstream 失败分类。

## 影响

用户需要打开完整对话中的请求记录才能知道失败原因，不符合看板卡片内嵌错误的规格。

## 根因

看板只查通用 error 事件；独立循环按既有协议把模型失败保存在回合和请求记录里，未必产生通用错误事件。

## 处理方式

独立失败卡片读取现有独立任务状态接口，仅用当前回合的固定失败分类；过往请求不冒充当前原因。未定副作用优先要求核对；配置入口先定位该任务对话再打开原配置界面，不自动重发请求。

## 验证

待纯函数、反向验证和离线浏览器复验。

## 时间线

- 2026-11-15 开启并修正：离线 503 夹具实际复现；新增当前错误、旧轮隔离与未定副作用三项用例，等待复验。

- 2026-11-15 复核：三项新增测试及停用映射后的反向失败通过；离线 503 分类显示正确。另修正捕获阶段跳转造成按钮动作丢失，深浅主题均实际打开对应配置弹窗，未自动重发（请求数仍为 1）。等待最终全量检查与修复提交。
