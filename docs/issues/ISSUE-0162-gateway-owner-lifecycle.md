## 现象与影响

两次启动同时接手残留记录时可同时获准，已有服务短暂返回 503 时也可能被接管。注册适配器失败会留下打开的数据库，第二次调用关闭还可能过早返回。可能中断正在工作的任务，或让用户无法立即重新打开工作台。

## 复现方法

在独立临时目录留下失效进程记录，同时发起两次启动。另用回环服务返回 503、令适配器注册失败、暂停或拒绝附件收尾，分别检查第二次启动或关闭。

## 根因与处理

残留文件的检查与删除之间可以交错，端口探测不能代表目录所有权。部分资源仅在正常退出时释放，关闭标记也早于实际收尾。用独立 SQLite 写事务独占数据目录，保留旧启动记录。启动失败按获取顺序倒序释放，重复关闭共享同一次收尾，单项失败仍释放监听和目录。
