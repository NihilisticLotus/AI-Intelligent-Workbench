# ISSUE-0101：非 git 项目里任何无关改动都阻止“应用结果”和撤销

## 现象

应用结果前把项目里所有文件与任务开始时比较，用户改了任务没碰的文件也会报“项目目录已发生变化”；撤销应用时同样。

## 处理方式

只检查任务要写的文件（应用）或当初应用的文件（撤销）；用户对其他文件的改动保留，不被覆盖，也不算冲突。写入后的核对也只核对这些文件。

## 验证

- 原两条“任意漂移都阻止”的用例改为：任务文件被改过时阻止应用；应用后已应用文件被改过时阻止撤销；新增无关文件不阻止应用和撤销且内容保留。
