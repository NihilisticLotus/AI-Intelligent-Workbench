# ISSUE-0144：任务分支提交过 .aic 后永远无法合并

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 中 |

| 开启 | 2026-11-19 |
| 关闭 | 2026-11-19 |

## 现象

Agent 强制提交过 .aic（或历史里出现过）时，合并直接失败“任务提交包含工作台专用目录 .aic”，压缩合并也一样，界面没有任何恢复办法。

## 复现步骤

1. 在任务副本里 git add -f .aic/TASK.md 并提交。
2. 合并到基准分支：两种方式都失败。

## 影响

任务成果无法通过界面合并，只能手动处理 git。

## 根因

mergeGit 对 .aic 历史一律报错，没有区分是否保留提交记录。

## 处理方式

压缩合并只发布最终树：先在任务分支把 .aic 的暂存状态恢复为项目基准并提交“移除工作台专用目录 .aic”，副本里的文件不动，然后照常合并。保留提交记录时返回 manual_required（新增原因 private_history，协议只增），网页提示改选“压缩成一次提交”。

## 验证

`workspace-operations.test.ts`：保留历史返回 private_history 且项目不变；压缩合并成功且项目与提交里没有 .aic。
