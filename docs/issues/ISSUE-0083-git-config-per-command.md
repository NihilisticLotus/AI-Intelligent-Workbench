# ISSUE-0083：每条 git 命令前都多启动一次 git config

| 项 | 值 |

| 关闭 | 2026-11-16 |

## 现象

为了屏蔽用户配置的过滤器和合并驱动，每条 add / diff / status / worktree 等命令前都先运行一次 `git config --get-regexp`，Windows 上进程启动开销翻倍。

## 处理方式

按（目录、git 目录、工作树）缓存查到的键名 2 秒，一次刷新里的连续命令只查一次；只缓存键名，不缓存值，失败不缓存。

## 验证

- 原“检出和暂存不执行用户过滤器”“未使用的合并驱动不阻断”用例继续通过；全量测试通过。
