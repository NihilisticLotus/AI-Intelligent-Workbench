## 现象

键盘和上下移按钮能调序；在内嵌浏览器中实际拖动卡片后顺序没有变化。

## 复现步骤

1. 在验收新建的临时 git 项目派发五个演示任务，并发上限为 2，前两项等待审批。
2. 拖动第二张排队卡片至第一张，观察显示和服务端队列仍保持原顺序。

## 影响

仅依赖 HTML 拖放事件不能完成此次浏览器的拖动验收，鼠标用户必须使用上下移按钮。

## 根因

未查明浏览器输入与 HTML 拖放事件之间的具体差异；没有证据说明服务端调序失败，键盘和按钮调用同一接口成功。

## 处理方式

拖动手柄增加指针捕获，在释放时按实际命中的卡片查找同一等待队列；仍保留 HTML 拖放、上下移按钮、Alt 方向键。释放到别列或别队列不发送调序。

## 验证

- 修正前：两次拖动未改变顺序，键盘与按钮成功。
- 修正后：待浏览器复验。

## 时间线

- 2026-11-15 开启：阶段 7 深色看板实际拖动未生效；增加明确的指针手柄，等待复验。
