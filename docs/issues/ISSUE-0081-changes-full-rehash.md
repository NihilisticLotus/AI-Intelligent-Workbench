## 现象

计算改动时对工作副本里每个文件做完整 SHA-256，而且每次工具结束都触发。大型游戏项目一轮几十次全盘读取。

## 处理方式

- 工具结束后的改动刷新合并为最多每 1.5 秒一次；回合结束、还原、合并等仍立即刷新。
- 工作副本文件哈希按（大小、修改时间、文件编号）缓存，刚修改不到 2 秒的文件不缓存（同 git 的同时刻写入处理）。缓存只用于显示改动；合并、应用、回滚的校验仍逐个重新计算。

## 验证

- 新增“同样大小内容变化也能发现”用例；原“工具结束发布改动合计”用例的事件次数断言由至少 2 次改为至少 1 次（两次刷新被合并），最终合计不变。
