# .agent：协作规则细则

入口是根目录的 [AGENTS.md](../AGENTS.md)：所有 AI Agent 都会读取它，核心规则写在那里。本目录放细则和模板，内容与 AGENTS.md 冲突时，以 AGENTS.md 为准，同时修正本目录。

| 文件 | 内容 |
|---|---|
| [commit-convention.md](commit-convention.md) | 提交规范：标题、正文三段式、type 和 scope、提交粒度、推送规则 |
| [repo-layout.md](repo-layout.md) | 目录结构、根目录白名单、每类文件放在哪里 |
| [records.md](records.md) | 文档、验收记录、开发笔记、问题收纳的存放位置、写法和溯源规则 |
| [templates/](templates/) | 开发笔记、问题单、验收记录的模板 |
