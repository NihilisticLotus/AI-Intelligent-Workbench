1. 新 TEMP 非 git 项目，独立任务使用既有智谱服务，3 次模型请求、2 次工具、512 输出 token、120 秒上限。

3. 按异常即停结束全部真实请求，不重试或修改预算。仅对已有文件成果继续界面应用和回滚核验。
