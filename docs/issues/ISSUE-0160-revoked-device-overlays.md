# ISSUE-0160：设备吊销后旧弹窗遮住手机配对页

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 中 |
| 发现于 | `16e0c4b`，[1.7 审查记录](../acceptance/step-1.7.md) |
| 开启 / 关闭 | 2026-11-21 |

## 现象与影响

手机已退回配对页，之前打开的命令面板仍在最上层，挡住配对码输入框，也可能继续显示上一会话的任务。

## 复现步骤

在隔离预览中用手机视口打开工作台的命令面板，再从电脑吊销该预览设备，检查配对页上是否还有打开的原生对话框。

## 根因与处理方式

菜单、对话框与提示保存在独立的界面状态中，工作台卸载后仍然存在。配对失效时清理这些状态，将等待确认或选择的操作按取消结束，同时清空上一个设备的页面数据与待处理事件。

## 验证

修复前 Chrome 在配对输入框出现后仍检测到打开的对话框。网页测试覆盖菜单、对话框和两个等待选择的操作。

## 时间线

- 2026-11-21 复核吊销后的手机界面，补充回归并修复。
