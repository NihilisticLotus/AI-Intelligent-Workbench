## 现象

全自动档对命令只要求“操作信息完整”，不要求命令能被解析。`powershell -Command "Remove-Item … C:\Users\…"`、`cmd /c "echo x > 原项目\a.txt"`、`node -e "…"` 这类命令的真实目标藏在引号或内联脚本里，“删除工作副本外文件”“直接修改原项目”两条始终禁止都不会命中，随后被全自动放行。影响工作台独立 Agent 和演示 Agent（第三方 Agent 本步只有只读 / 需审批）。

## 处理方式

全自动只放行能核对范围的操作（与规则 allow 的条件相同：路径都在工作副本内，命令不含 -c / -e / 重定向 / 变量 / 多条命令）；其余回到审批。

- independent-task-runtime.test.ts：原“全自动执行”用例改用可核对的 `node --version`；新增“全自动下 -e 内联脚本改为审批”。
