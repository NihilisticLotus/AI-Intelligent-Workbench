# ISSUE-0109：非 git 副本的交接预览遗漏最后一次快照之后的文件

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | 验收未通过 |
| 严重程度 | 中 |
| 发现于 | [1.6 阶段 2 验收](../acceptance/step-1.6.md) |
| 开启 | 2026-11-18 |
| 关闭 | 2026-11-18 |

## 现象

任务结束后在临时副本创建的 `level.txt` 没有出现在交接预览。

## 复现步骤

1. 在临时非 git 项目完成一轮演示任务。
2. 向副本写入一行新文件，立即调用交接预览。
3. 核对工作区文件、预览中的文件清单和行数。

## 影响

源数据漏掉的改动无法通过后续覆盖校验补回。

## 根因

普通改动面板对非 git 副本使用最近的影子快照。最后一次快照之后的编辑尚未记录。

## 处理方式

交接预览在工作台私有索引中比较副本当前内容与基准。同一次工作区操作还读取任务分支最近的提交，预览不创建检查点。

## 验证

修复前清单为空，修复后同一用例列出 `level.txt` 和新增一行。四个定向用例通过。

## 时间线

- 2026-11-18 定向验收发现，在临时副本复现并修复。
