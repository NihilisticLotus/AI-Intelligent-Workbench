## 现象

起始页加了图片附件时，推荐规则按 Agent 列表顺序找第一个能看图的模型。列表里演示 Agent 排第一，它的“演示-快”标为能看图，于是推荐总是“演示 Agent”，它不调用真实模型。未登录、出错的 Agent 也可能被推荐，采用后无法派发。

## 处理方式

只在状态为“就绪”的 Agent 里找，真实 Agent 优先；演示 Agent 只在没有其他候选时才推荐。没有图片时“推荐上次在这个项目用的 Agent”的规则不变。

- 17890 开发预览起始页加一张合成 PNG、写描述后，推荐从演示 Agent 变为“Claude Code · Default (recommended)”；未派发。
