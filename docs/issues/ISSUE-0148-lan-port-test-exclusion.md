## 现象

阶段 5 的第一轮 `npm test` 在 Gateway 端口顺延用例中收到 `EACCES`，当时选中的相邻回环端口为 4689。其余 Gateway 用例和适配器、协议、网页测试通过。

## 复现步骤

1. 在 Windows 运行默认测试。
2. 旧夹具占用系统分配的回环端口。若相邻端口不可绑定，Gateway 在该端口上无法开始顺延测试。是否遇到取决于系统分配结果。

## 影响

顺延测试可能在发送请求前失败。本次失败没有触及真实局域网地址、Windows 防火墙或系统设置。

## 根因

夹具只验证第一个端口可用，把「系统分配了一个端口」当成相邻端口也可绑定的保证。Windows 保留端口或同时占用都会使该假设失效。

## 处理方式

夹具先在 `127.0.0.1` 试绑定相邻端口。遇到 `EADDRINUSE` 或 `EACCES` 就释放这一对端口并重新挑选。实际验收依旧占住首个端口，确认 Gateway 精确顺延一位，第二监听共用实际端口。

## 验证

Gateway 的 11 项局域网专项通过。默认全量复跑 1173 项通过、3 项跳过，类型检查和构建均通过。
