# ISSUE-0161：正常顺延多个端口时局域网用例误报

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 中 |
| 发现于 | `16e0c4b`，[1.7 审查记录](../acceptance/step-1.7.md) |
| 开启 / 关闭 | 2026-11-21 |

## 现象与影响

Gateway 允许从指定端口起尝试十次绑定。顺延测试要求正好使用下一个端口，Windows 把它分配给其他连接时，产品正常运行，默认验证却报错。

## 复现步骤

重复本机回环顺延用例，第 4 次观察到预期端口为 4801，实际使用了 4802。只使用独立测试服务。

## 根因与处理方式

[ISSUE-0148](ISSUE-0148-lan-port-test-exclusion.md) 增加了探测以排除系统保留端口。探测结束到 Gateway 开始监听之间，端口仍可被占用。本次测试独立抽取候选端口，保留两个相邻端口，检查 Gateway 在承诺的范围内顺延，并在实际选中的端口核对两个监听的 HTTP、WebSocket 和关闭行为。

## 验证

在保留两个端口的测试中恢复原先“起点加一”的断言会稳定失败。修复后的顺延用例单独连续运行 40 次全部通过。
