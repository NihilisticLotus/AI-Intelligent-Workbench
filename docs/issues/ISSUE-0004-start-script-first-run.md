## 现象

`启动 AI Console.bat` 有两条路径没在实际环境里跑过：首次运行时自动执行 `npm install`；没装 Node 时弹出中文提示并打开下载页。开发机已经装好依赖和 Node，所以测不到。

## 影响

用户第一次在新电脑上双击时，可能卡在安装依赖这一步，或者看不到提示。

## 处理方式

找一台没有 node_modules 的环境实测，或者在 Windows 沙盒里测：删掉 node_modules 后双击，以及在 PATH 里去掉 Node 后双击。
