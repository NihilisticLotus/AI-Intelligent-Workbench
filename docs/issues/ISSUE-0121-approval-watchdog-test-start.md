# ISSUE-0121：无回应计时用例在审批请求登记之前快进时间

## 现象

一次全量离线运行中，期望等待审批时读取到运行中。

## 复现步骤

1. 运行默认测试中“等待审批期间不计时”用例。临时项目的权限上下文需要异步读取。

## 影响

会把正常的处理耗时误报为审批看门狗失败。

## 根因

虚拟时钟推进零毫秒不能证明真实异步读取与审批登记已完成。

## 处理方式

先等本任务的 approval.requested 事件，再推进原用例的 700000 毫秒。保留 waiting 及没有错误事件的断言。定向复验通过。

## 验证

阶段记录见 [1.6 验收](../acceptance/step-1.6.md)。
