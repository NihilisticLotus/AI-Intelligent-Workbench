## 现象与影响

看板提示调序失败后，任务仍按新顺序运行。取消或释放时若通知失败，也可能中断收尾。

## 复现方法

在有两项等待任务时注入通知保存失败，分别调序、取消和释放名额。

## 根因与处理

调序保存失败后恢复原队列位置。批量任务通知按事务写入。取消和释放后只发送一次更新，保存异常时记录失败并完成交接。

## 验证

旧版调序失败后原第一项落到第二位。修复后顺序保持，取消和释放期间的写入失败也不妨碍下一任务获得名额。
