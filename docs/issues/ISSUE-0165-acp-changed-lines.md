# ISSUE-0165：工具改动摘要多算尾部空行和两处修改之间的原文

## 现象与影响

创建以换行结尾的两行文件会多算一行，相隔数行的两处修改还可能把中间原文计入增删。对话和详细面板中的改动范围失真。

## 复现方法

给 ACP 工具发送带 CRLF 的新增文件和中间保留一行的替换，比较文字摘要与结构化改动数。

## 根因与处理

旧算法按换行直接切分，再把公共前后缀之间的所有行都当作修改。按实际行切分，计算保留下来的有序公共行。超出精确计算限额且存在歧义时返回未报告。

## 验证

`packages/adapters/test/details.test.ts` 和原有 `contract.test.ts` 同时核对纯文本、结构化结果及追加行的兼容行为。
