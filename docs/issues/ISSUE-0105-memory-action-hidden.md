# ISSUE-0105：主对话里的“记为约束”跟随隐藏的消息标题消失

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | 验收未通过 |
| 严重程度 | 中 |
| 发现于 | [1.6 阶段 1 验收](../acceptance/step-1.6.md) |
| 开启 | 2026-11-18 |
| 关闭 | 2026-11-18 |

## 现象与复现步骤

在开发预览创建临时 git 项目并派发演示任务。消息原文已出现，浏览器里找不到对应操作。

## 影响

用户无法把自己的原话保存到任务账本。

## 根因

既有样式隐藏用户消息的头像和标题，新操作也被放进标题。

## 处理方式

把按钮放在消息气泡下面，继承已有按钮样式。

## 验证

日间点击后显示“已记为约束”。切换夜间并刷新，按钮仍为已保存状态。

## 时间线

- 2026-11-18 开启并定位于阶段 1 本地验收。修复后已完成上述定向复验。
- 2026-11-18 修复已推送至 main，提交 `667fa8e`。
