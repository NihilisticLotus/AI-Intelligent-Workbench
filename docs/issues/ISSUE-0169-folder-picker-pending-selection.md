# ISSUE-0169：目录读取未确认时可以把父目录误选为项目

## 现象与影响

点进子目录后，读取较慢或失败时仍可提交上一个路径。部分错误界面没有重试按钮。项目可能登记到另一个文件夹，后续任务会在那里工作。

## 复现方法

进入父目录，延迟子目录结果，再让其首次返回 503，观察确定按钮并尝试重试。

## 根因与处理

显示名称、路径和目录列表分别更新，失败时保留可提交的旧结果。目录结果成功后统一更新路径、名称和导航记录，读取期间和出错后禁用确认。重试沿用原目标，丢弃过时结果，退出设备会话会结束待选目录及交接对话框。

## 验证

浏览器在原构建复现可提交父目录，修复构建检查延迟、失败、重试和最终选中的子目录。
