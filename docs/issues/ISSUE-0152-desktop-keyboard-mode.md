# ISSUE-0152：桌面小窗口调整高度被当成软键盘

| 项 | 值 |
|---|---|
| 状态 | fixed |
| 类型 | bug |
| 严重程度 | 低 |
| 发现于 | [第 1.7 步代码审查](../acceptance/step-1.7.md) |
| 开启 | 2026-11-19 |
| 关闭 | 2026-11-19 |

## 现象

可视视口处理作用于 1279 像素以下所有窗口。在宽度不超过 1279 像素的电脑浏览器窗口里，光标在输入框时把窗口高度拉低 120 像素以上，页面进入“键盘模式”，对话输入框工具条只剩发送按钮，底部导航隐藏。

## 复现步骤

1. 电脑浏览器窗口宽约 1200 像素，打开任务对话。
2. 点进输入框，再拖动窗口下沿缩短高度。
3. 工具条被隐藏，直到输入框失去焦点。

## 影响

桌面小窗口下输入时工具条意外消失。手机和平板不受影响。

## 根因

键盘判定只看“输入中 + 可视高度比静止高度小 120 像素”，没区分是否触屏设备。

## 处理方式

只在 `(pointer: coarse)` 的触屏设备上把输入中的高度收缩判为键盘；可视高度变量照常更新。

## 验证

新增安装级用例：触屏收缩识别为键盘，非触屏收缩不进入键盘模式。临时撤掉修复后后者失败，恢复后通过。
