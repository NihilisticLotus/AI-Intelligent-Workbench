## 现象

adapters 的 textResponseError 把“本轮只有一条消息、没有工具、短于 600 字、以 model is not supported 等开头”的回复当成上游错误：任务暂停，模型在选择器里标“上次失败”。

## 影响

用户问这类报错是什么意思、Agent 的简短回答恰好以这些词开头时会被误判。概率低。

## 处理方式

未改。除 Codex 代理的完整固定封套外，其余几条开头匹配可以收紧为完整句式，或只暂停不打失败标记。真实失败路径 2026-11-10 刚验证通过，收紧前要保证那条路径不退化。
