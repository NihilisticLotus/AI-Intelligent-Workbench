# ISSUE-0079：数据库迁移抛错时没有关闭连接

## 现象

迁移失败后 openDb 没有返回数据库对象，调用方无法关闭已经打开的连接。Windows 临时数据库清理随后出现 EPERM。

## 复现步骤

1. 在测试自己的临时目录创建数据库并设置不支持的较高 user_version。
2. 调用 openDb，收到版本不支持异常。
3. 立即删除临时数据库，缺少关闭逻辑时 Windows 拒绝。

## 影响

启动或升级失败时遗留数据库文件句柄，妨碍故障恢复与测试清理。

## 根因

连接打开后的初始化 PRAGMA 与 migrate 没有异常关闭路径。

## 处理方式

初始化或迁移抛错时关闭本次连接，保留原始异常。已有事务回滚逻辑不变。

## 验证

新增临时数据库回归，反向回归与全量结果完成后追加。
