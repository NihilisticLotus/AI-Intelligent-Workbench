## 现象

项目设置里“带入工作副本的文件”匹配到未被 .gitignore 忽略的本地文件时，合并前的 `git add --all` 把它提交进任务分支（可能含密钥）；同时它在项目里是未跟踪文件，合并预检把它当成未提交改动，合并一直报“项目有未提交的文件”。

## 处理方式

合并前自动提交时把带入的文件从暂存区移出，不进入任务提交；合并预检只忽略这些带入文件本身的“未跟踪”状态，任何已跟踪文件的改动仍阻止合并。

## 验证

- 新增用例：带入 local.json 的任务改了 notes.txt 后正常合并，local.json 不在任何提交里，项目里的原文件不变。临时去掉修复时失败。
