## 现象

临时目录采用 Windows 8.3 短名称时，普通操作无法生成“总是允许”预览；目录联接指向原项目时返回询问，未按预期直接拒绝。

## 复现步骤

1. 在测试新建临时目录，分别创建原项目和副本目录。
2. 输入目录使用 TEMP 的短名称，目标经异步 realpath 转成长名称。
3. 执行 permission-rules.test.ts，预览与目录联接用例失败。

## 影响

同一个目录被错误判为副本外；原项目保护也可能漏掉别名路径。该实现尚未提交或发布。

## 根因

只规范化操作目标，没有同步规范化副本根和原项目根。

## 处理方式

判定前统一对两个根调用 realpath；无法确认根时拒绝操作。目标仍解析最近存在的父目录，覆盖尚未创建的文件和目录联接。
