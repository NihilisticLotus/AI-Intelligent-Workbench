# ISSUE-0067：从起始页返回首页后，有任务仍显示空列表文案

## 现象

侧栏已有任务，直接打开新建起始页并返回首页，主区仍写“还没有任务”。

## 复现步骤

1. 在有历史任务的开发工作台打开起始页，刷新以模拟直接进入地址。
2. 点击“返回”。原路由默认首页，按既定规则不自动跳进最近任务。
3. 侧栏能看到历史任务，但主区错误显示空任务文案。

## 影响

误导用户以为已有任务不见了；任务数据没有丢失，新建入口仍可用。

## 根因

Home 原先只在无任务时可达，固定使用空列表文案。起始页允许返回首页后，这个假设不再成立。

## 处理方式

按当前任务列表判断文案：有任务显示“选择一个任务，或新建任务”及继续已有对话指引；真正无任务时保持原指引。不改变返回路由或自动打开行为。

## 验证

- 新增实际组件静态渲染测试，覆盖有任务与真正空列表；修复后通过。
- 临时禁用任务存在判断，测试因仍显示空列表失败；恢复后通过。
- 完整检查与浏览器修复后结果待追加。
